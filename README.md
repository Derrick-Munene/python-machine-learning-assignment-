#what is supervised machine learning?

supervised machine learning is a type of machine learning model where the model learns from a **labeled dataset **.
unsupervised machine learningis a type of machine learning where the model works with an **unlabeled dataset**
**supervised learning ;** uses data with known target labels to predict specific outputs for for future new data *unsupervised learning ;* uses data without labels to find hidden structures,clusters,or patterns insidethe data.
**fit();this a method calculates the model parameters or adjusts weights using the training data.**predict();**this method uses the learned parameters to assign a label or calculate a target output   for a new incomimg data points.
